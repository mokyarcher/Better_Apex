# 游戏状态浮窗（Display）

状态：现行　更新：2026-11-02

## 功能行为

设置页开启后显示自动记录阶段、暂停/伤害重试提示、保存进度，以及 Better Apex 自身进程树CPU与专用提交内存。默认关闭。可选上/下居中、40%—100%不透明度；设置保存到新版数据目录 `display-settings.json`。损坏设置关闭浮窗并报告错误，不影响战绩记录。

15秒预览只在主窗口客户区临时显示，不启动游戏采集或生成战绩；预览到期、关闭开关或保存设置时结束。

正常显示要求选定游戏窗口在前台且未最小化；切到工具或其他应用时隐藏。原生辅助窗口不激活、不抢焦点、鼠标穿透，不成为采集目标，也不创建第二个WebView。浮窗随主程序退出清理。

## 指标定义

- 每2秒最多采样一次；关闭/隐藏后不采样进程指标。
- 统计主进程和后代进程（含WebView2），不包括游戏或其他程序。
- CPU按进程时间差除以逻辑CPU总算力，归一化到0—100%；进程首次采样显示“采样中”。低频采样可能漏计刚退出进程的末段CPU。
- 内存采用 `PROCESS_MEMORY_COUNTERS_EX.PrivateUsage` 总和，即专用提交量；不是任务管理器默认的专用工作集。不可读取时显示部分错误/未知，不伪装为0。

## 兼容与验收

位置避开已知OCR区域，并按DPI约束在客户区中间范围；不增加截图或OCR频率。当前设计适用于窗口化/无边框。Apex覆盖效果、HDR、独占全屏和不同桌面缩放组合须在目标游戏电脑验证，开发机组件测试不能替代该验收。
