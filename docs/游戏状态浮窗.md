# 游戏状态浮窗（Display）

更新：2026-11-01。

在“设置 → 游戏状态浮窗 · Display”开启，可显示00加载、01选传奇、02局内、03结算／保存进度，以及暂停／伤害重试提示、已存记录数量、Better Apex自身CPU和专用内存占用。

- 默认关闭。位置可选上方居中／下方居中，不透明度40%—100%，选择后保存；设置写入新版数据目录display-settings.json，重启保留。读取损坏设置时关闭浮窗并报告错误，不影响战绩功能。
- “预览15秒”临时显示在主窗口客户区，不启动采集，不生成战绩；到期自动隐藏。关闭开关或保存设置会结束预览。
- 正常模式仅在选定游戏窗口位于前台且未最小化时显示；切到工具或其他应用自动隐藏。浮窗不会成为游戏采集候选，不抢焦点，所有鼠标操作穿透。它是原生Windows辅助窗口，不是另一个Tauri/WebView业务界面。
- 两个位置避开现有页面判定、昵称和战绩数值区域；高DPI时宽度限制在客户区中间33%，避免桌面缩放把浮窗扩入识别区；浮窗本身可能出现在DXGI证据截图的非识别区域。不修改采集遮挡保护，不增加截图／OCR次数，不影响现有01只监视、02每局单次昵称及03伤害重试规则。
- 当前采用桌面置顶窗口，适用于窗口化／无边框窗口。独占全屏、HDR、不同桌面缩放组合及真实Apex覆盖效果仍需游戏电脑验证；不注入游戏、不使用RTSS或图形Hook。

## 指标口径

每2秒最多采样一次。关闭或隐藏时不枚举进程或采样指标；只是维护低频窗口可见性检查。

统计当前Rust主进程及其后代（包含WebView2），不统计游戏或其他应用。进程CPU时间由GetProcessTimes读取，对两次读数取差，并按可用逻辑CPU总算力归一化为0—100%；进程新建或PID复用不冒充已有累计时间，第一次显示“采样中”。采样间已退出的子进程末段CPU时间可能未计入，指标为低频估算。

专用内存是PROCESS_MEMORY_COUNTERS_EX.PrivateUsage合计，即进程树专用提交量，按1024×1024换算显示；它不是任务管理器默认“专用工作集”物理内存列，数值不应直接逐项对比。某个子进程不可读时明确提示部分数据不可读；完全失败显示未知及错误，不伪装成0。

后台原生GDI绘制，无新增渲染器或外部程序。浮窗关闭／隐藏时不进行资源采样，退出主程序时关闭辅助窗口并回收线程、句柄和GDI对象。

## 验证

定向测试覆盖进程树边界、PID复用／CPU归一化、设置持久化／输入校验、负坐标显示器／DPI位置、实际本进程采样；自有测试窗口验证预览显示、鼠标穿透、不抢前台焦点、禁用隐藏、排除采集候选及退出回收。测试不连接游戏，不写正式战绩。
