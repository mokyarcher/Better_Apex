# 旧版经验与迁移边界

当前产品以 `rust-app/` 下的 Rust + Tauri + Vue 实现为准。旧版 WPF 的源码、窗口、OCR 和存储实现不参与新版编译或运行；本文件只保留仍有价值的产品约束和迁移边界，不作为旧版操作手册。

## 保留的经验

- OCR 未识别必须保留为空／待核对，不能伪装成真实的 0；昵称身份需要证据，不按队伍顺序或剩余位置猜测。
- 结算数字与能关联到的昵称应分开处理；对局名单与结算卡片使用一对一匹配，证据不足时保留未知。
- 保存应保留与结果对应的截图证据，并通过事务、幂等和去重避免留下半条记录或重复战绩。
- 采集应限定目标窗口、控制频率，不读取游戏内存；本地记录和截图不得上传。
- 旧版 `data/` 与新版 Tauri 应用数据目录彼此独立。新版不迁移、改写或自动读取旧战绩。

以上约束在当前 Rust 代码、`agent.md` 和自动记录／存储文档中维护；修改行为时以当前实现和对应阶段文档为准。

## 仍复用的资源

旧 WPF 源码已从工作区移除。当前可选 Tesseract 引擎仍使用原有的 `chi_sim.traineddata`、`eng.traineddata` 和随附许可文件；这些资源单独保留在 `assets/tesseract/tessdata/`，由 `scripts/Prepare-RustResources.ps1` 复制到 Tauri 资源目录。PP-OCR 模型由 `scripts/Prepare-PpOcr.ps1` 单独准备。

开发机上的旧战绩位于根目录 `data/`（Git 忽略）。它不是新版运行依赖；`compatibility-cli` 仅用于显式的只读结构／文件校验。保留这份本机数据以便用户自行查看或备份。

## 验证资料

旧 WPF 的窗口与自动流程验证源码已删除。当前验证入口是 `rust-app/src-tauri/` 的 Rust 测试和 `rust-app/tests/` 的前端测试；真实 Apex 时序、按键和性能仍以游戏电脑实测为准。迁移阶段文档保留当时的决策背景，不代表旧版源码是新版依赖。
