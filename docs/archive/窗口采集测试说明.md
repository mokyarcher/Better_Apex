# 窗口采集测试包：步骤 A

## 在哪台电脑运行

在开发电脑编写、打包，把整个 ZIP 复制到运行 Apex 的另一台 Windows 游戏电脑。工具和游戏在同一台电脑运行，此版本不通过网络传输游戏画面。

测试包包含 .NET 运行时，无需安装 .NET SDK 或复制项目源码。保留解压后的全部文件和子目录，不单独拷贝 EXE。要求 Windows 10 2004 或更新版本、Windows 11、x64；先使用 SDR 和无边框窗口测试。

## 开始检查

1. 将 ZIP 完整解压到可写目录，例如 `D:\Tools\BetterApex`，不要在压缩包内直接运行。
2. 启动 Apex，双击解压目录中的 `启动.cmd`，或直接打开 `BetterApex.exe`。
3. 点击主界面右上角“窗口采集”。点击“刷新窗口”，选择 Apex 游戏窗口。
4. 点击“开始预览”，切回游戏进行一局操作。Windows 可能为正在捕获的窗口显示系统边框。
5. 切回工具，检查预览是否属于选定的游戏，左下角队伍栏、右上角小队栏、上下左右边缘是否完整。原生 2K 无边框窗口正常应显示 `2560 × 1440`。
6. 点击“保存当前截图”，选择位置，保存一张原始像素尺寸的 PNG。不是保存缩小后的界面预览。保存的是点击按钮时显示的那一帧，后续画面不会替换它。
7. 检查移动窗口、切出游戏、最小化再恢复时的状态。黑屏、没有新帧、最小化时应提示等待，不能假装旧图仍是实时画面。
8. 点击“停止采集”，预览停止，保留最后一张已显示截图供手动保存。重新开始后应取得新画面；关闭采集窗口会释放捕获会话。

预览每秒最多更新约 2 帧，属于此步骤的检查频率，不是录像帧率。此步骤不启动自动 OCR、不自动判断入局或结算、不自动保存战绩。原有导入图片、识别、手动保存和历史入口保留。

## 测试反馈

请记录：Windows 版本、游戏分辨率、窗口/无边框/独占全屏、HDR 是否开启、预览显示尺寸，以及是否黑屏、缺边或停止后仍更新。出现画面问题时，可提供工具界面截图；能正常导出时，优先保留导出的原图用于后续标定。

本机已用程序创建的彩色测试窗口检查 Windows 捕获和客户区裁剪。Apex 的画面兼容性与帧率影响，仍需要在游戏电脑实测，不能用普通窗口测试代替。

## 数据与依赖

- 此包不带开发电脑已有的战绩数据库、截图或测试记录。原有历史若需迁移，请先关闭软件，另行完整备份和复制旧 `data` 文件夹；本步骤无需迁移历史。
- 通过包内启动脚本运行时，本地战绩位置为包内 `data` 文件夹。窗口预览不会向其中创建战绩。
- 截图预览不依赖中文 OCR 语言组件；若使用原有“对局昵称”，游戏电脑仍需具备 Windows 简体中文 OCR 支持。
- 原有结算 OCR 的原生库可能需要微软 Visual C++ x64 运行库；这与 .NET SDK 不同。若只有 OCR 提示运行依赖缺失，可安装[微软提供的 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)后重试，版本与支持说明见[微软文档](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。
- 不要求以管理员身份运行。若未发现窗口，先确认游戏窗口已打开并刷新列表；黑屏时先用 SDR、无边框窗口检查。
