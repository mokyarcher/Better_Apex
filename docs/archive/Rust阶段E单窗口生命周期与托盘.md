## 操作规则

- 主窗口始终使用同一个 `main` 窗口。托盘左键打开并聚焦已有窗口，右键显示操作菜单。
- 菜单提供“打开 Better Apex”、“开始自动记录/停止自动记录”和“退出程序”。自动记录菜单文字随运行状态更新；托盘开始使用主界面最近选定的游戏窗口。
- 自动状态改变时由 Rust 直接更新菜单并通知界面，不再依赖前端的 2 秒状态查询。窗口恢复后补读后台快照和历史；托盘隐藏期间不请求预览图片或历史列表。
- 自动记录运行中点击主窗口关闭按钮时，窗口隐藏到托盘，采集和监测保持运行。托盘图标仍可打开主窗口或退出程序。
- 未运行自动记录时点击关闭，正常退出；正在执行的采集会在应用退出流程中停止。
- 单实例使用 Windows 命名互斥锁和激活事件。再次启动会请求已有实例显示主窗口，然后退出新进程。
- 若托盘创建失败，自动记录期间会阻止主窗口消失并提示先停止任务，避免留下无法操作或无法退出的后台实例。
