日期：2026-10-31；版本：0.2.0。

> 历史阶段记录：下文保留阶段 B UI 原型的当时状态。C1—D 识别、存储和自动记录已在后续接入；当前状态见 [Rust＋Tauri 改造计划](Rust-Tauri技术与UI改造计划.md)。

本次推进界面和操作组织，不重复验证已经通过的采集、OCR 通路。本版本仍未接入完整识别、战绩写入和自动记录，请继续用旧版记录正式对局。

## 这次可以检查什么

- 自动记录、战绩记录、手动导入、设置统一在一个主窗口内切换。
- 自动记录页集中展示游戏连接、本场流程和最近记录；真正的“开始自动记录”尚未接入，因此明确禁用。原有采集检查收进“检查游戏画面”，不再占据主界面。
- 战绩页展示新版本地记录；当前版本尚未接入保存，因此可用示例数据预览列表与详情。旧版战绩不会导入新版。
- 手动导入提供截图预览、页内放大及现阶段伤害／昵称区域识别；切换页面保留当前截图和结果。
- 设置页统一展示本地保存说明、2 秒采集间隔和迁移进度。
- 战绩页和设置页提供“示例效果”。示例始终标注，不会写进数据库。

## 使用方法

运行本地编译版 `BetterApex-Rust-Lab.exe`，保留旁边的 `resources`。

1. 先查看首页，再到战绩页点击“查看示例效果”，检查列表、详情及页面切换是否顺手。
2. 旧版战绩不支持导入；新版存储接入后，从新版开始累积记录。
3. 手动导入一张已有图片即可检查预览和页内放大，不需要为本轮准备新图。
4. 当前关闭主窗口即退出；收起到托盘属于后续步骤，尚未接入。

本轮主要反馈布局、字号、操作顺序和页面切换体验。无需重新测试多局采集或提供额外游戏截图。
