# Rust 阶段 C3：手动关联与战绩保存

日期：2026-10-31；版本：0.2.0。

## 操作顺序

1. 在“手动导入”选择“局内队伍昵称”，识别02画面的左下三人昵称（手动单图只读一次）。该名单暂存于应用内存，并显示在识别结果下方。
2. 选择同一局的结算图并识别排名、小队总击杀和三名玩家数据。
3. 在“关联本场昵称”中按结算卡片位置选择对应的局内玩家；系统只带入选中候选，用户仍可编辑保存昵称。
4. 逐名勾选“已核对”以确认昵称，并可选择本人对应的位置。任何未确认的名称或本人身份都以待核对/未知状态保存。
5. 保存后，数据库与 `evidence/` 同时保存战绩、结算图和可选的局内HUD截图；历史详情提供两个来源图的查看入口。

结算识别后昵称输入初始为空，不预填结算 OCR；只能从同局名单明确选择或由用户手动填写并核对。没有姓名时可保存数值与未知归属，保存层不会从结算文字兜底补名。手动输入来源标为 `manual`；自动流程仅使用 `voted_roster`。暂存名单不会跨应用重启保留，避免上一局队伍误用。

本流程没有模糊匹配、自动本人识别或昵称强制修正规则。玩家关联完全由用户选择，保存阶段不会推断队伍位置对应关系。

## 验证状态

已检查 Vue/TypeScript 生产构建，Rust 存储定向测试覆盖三名玩家注释、局内图/结算图留存、重复保存和真实结算图识别结果。实际交互和截图取自另一台游戏电脑，需在该电脑运行新版后做一次端到端验收。
