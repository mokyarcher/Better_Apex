**这是从较高分辨率缩小的派生测试图，不是原生1080P游戏截图。** 可用于检查1080P坐标、页面检测与OCR通路，不能据此证明原生1080P识别精度或游戏性能。不同图片可能来自不同队伍，不能当作同局连续采样投票。
